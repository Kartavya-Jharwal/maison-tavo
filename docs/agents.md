# Agents, sound and the art of exchange

This page describes proposed experiences in the Maison Tavo case study. They are not live shopping features.

## The Kansa Bell Resonance Ritual

The opening ritual would model the decaying harmonics of high-tin bell bronze (22% tin, 78% copper) with the Web Audio API. Its fading overtones would time restrained typography reveals. Sound would require an explicit visitor action, with silent and reduced-motion alternatives. The existing storefront sound toggle is a separate opt-in cue, not a calibrated alloy simulation.

## Mol-Bhav: the agent-to-agent arena

*Mol-bhav* describes mutual negotiation as a relationship of respect between patron and artisan, rather than a coupon mechanic. The proposed arena would let a visitor initiate an exchange between a buyer agent and Kansa. A deterministic state machine would examine inventory age, bundle elasticity and a first-sale-of-the-day *bohni* rule, then issue an expiring, cryptographically verifiable proposal token.

In a later connected version, an authenticated MCP or webhook endpoint could accept outside-agent messages and display a redacted packet trace. The displayed trace would identify the source and whether a human relayed messages. Proposal terms would be verified against live Shopify stock and price before checkout. Authentication, rate limits, expiry and replay protection are prerequisites for a real offer.
