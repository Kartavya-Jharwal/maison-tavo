# Maison Tavo

Maison Tavo is a headless storefront built with [Shopify Hydrogen](https://shopify.dev/custom-storefronts/hydrogen) and [React Router](https://reactrouter.com/).

The shop catalog, cart, customer accounts, and content come from Shopify. This repository is the storefront that renders them.
