# Maison Tavo

Maison Tavo is a premium hybrid-metallurgy cookware concept brand. **Kansa** is its voice assistant, companion webapp and proposed negotiating agent. The flagship uses a custom Shopify Horizon/Liquid theme; Hydrogen is a secondary preview.

The governing thesis: **a brand a machine can find, understand and negotiate for, where the tool is sacred.** The public MkDocs site is the research and portfolio front door; the designed Shopify development store remains password-gated. One product source should feed its human page, agent data and voice content.
